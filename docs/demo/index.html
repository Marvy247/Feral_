03 / what runs where

The contract enforces; the mirror explains

Feral's engine runs twice. The Rust vault recomputes the fund-moving checks from its own storage on every call, so a compromised off-chain process cannot widen the limits. The TypeScript mirror runs the same checks plus the quote-level ones the contract cannot see, before submission, so refusals come with an explanation.
